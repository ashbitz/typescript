# TypeScript Training

Este repositorio contiene ejercicios y prácticas de TypeScript.

Incluye:

- Laboratorio práctico 1: Inicialización y lógica pura  
  Funciones y utilidades básicas con tipos

- Laboratorio práctico 2: Arquitectura de acceso a datos  
  Modelado de dominio, uniones discriminadas y genéricos

- Laboratorio práctico 3: Desarrollo de UI estricta y documentación final  
  Utility types, análisis exhaustivo y base para React
